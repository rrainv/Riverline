## Intentionally Left Behind or Deferred
- **Left behind permanently:** `app/src/core/logic.js`, all `*-bootstrap.mjs` / `*-workspace.mjs` / `*-view-model.mjs` / `*-presentation*.mjs` glue, `account-identity/`, `account-profile/`, `authentication/`, `sync/`, `tutorial/`, `welcome-orientation*`, `app/assets/audio/foley/`, and all source-shape / CSS-reading tests.
- **Deferred to their feature slices:** `personal-strategy/`, `training-memory/`, `saved-study-objects/`, and full hand-review / hand-history storage (now implemented across Slices 1–5; remaining future items tracked in `docs/STATE.md` and `docs/IDEA_BANK.md`).
- **`engine/solver/` (Offline DCFR River & Turn-to-River Pilot, `tools/river_toy_exact.py`, `tools/pushfold_exact.py`, `tools/build-preflop-equity-matrix.mjs`, `tools/benchmark-solver.mjs`, `tools/solve-pilot.mjs`):** Clean-room Discounted CFR (`alpha = 1.5, beta = 0, gamma = 2`) implemented directly from Brown & Sandholm (2019), *"Solving Imperfect-Information Games via Discounted Regret Minimization"* (arXiv:1809.04040), paired with independent `O(R^2)` pairwise best-response verifiers (`computeRiverBestResponse`, `computeTurnBestResponsePairwise` in `best-response.ts`), raked & rake-free terminal evaluation (`rakePct`, `rakeCapBb`), Turn-to-River extension (`turn-subgame.ts`) with exact suit-isomorphic river compression + stratified weighted sampling (`river-compression.ts`), `Float32Array` river-subtree buffers, full Turn/River decision-node inspection (`tree-inspector.ts`), `evaluateSevenCodesUnchecked` as the single evaluator authority (`B6`), exact `169 x 169` preflop all-in equity matrix (`tools/data/preflop-equity-169x169.json`, `1,624,350` ordered pairs) driving `pushfold-hu-nash-exact-v2` (`< 0.00002 bb/hand` exploitability), automated benchmark harness (`npm run benchmark:solver`), and pre-solved static pilot artifacts (`pilot-catalog.ts`, `pushfold-table.ts`).
